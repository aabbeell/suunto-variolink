Six ways to draw the thermal page

All six run in the SuuntoPlus simulator on the Race S display (466 px) with the same synthetic flight: a glide in from the west, then 22-second circles in a 5 m/s west wind with the core on the east side, captured 35 s into the climb. None of these is on the watch yet; the watch has the map test build (version A) from 12:46.

What the survey says

  • No watch product draws a thermal map today. Suunto's own Variometer, Tracerlink (Apple Watch, also reads the UltraBip) and the Wear OS varios are number tiles only.
  • The most praised big-screen designs draw few marks: a core circle, the predicted turn, lift as line width (Skytraxx 5, XCTrack).
  • Nearly everyone shows these while thermalling: instant climb (largest), altitude, thermal gain, average climb, wind, ground speed.
  • Almost all switch to the thermal page by themselves when circling starts, as VarioLink does.

Questions for the brainstorm

  1. Map first (A, B, F) or number first (C, E)?
  2. Keep the polar assistant (D) as an idea, or drop it?
  3. Centre on you (B) or on the thermal (F)?
  4. Which fields: climb, TC, gain, altitude, wind?

My pick: B as the base, with the TC and gain line, and F's core centring once the core is known.
